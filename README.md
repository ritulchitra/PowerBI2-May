# Adidas Sales Performance Analysis (2020-2021)

This project analyzes Adidas sales performance data from 2020–2021 to uncover key insights for growth. The dataset was sourced from an open GitHub repository and was later transformed, visualized, and analyzed using Excel and Power BI.

## 🔍 Project Objective

To explore Adidas sales data, identify patterns and trends, and provide meaningful insights using interactive dashboards created in Power BI.

---

## 📁 Data Source

The original dataset was obtained from this GitHub repository:  
[Ernest-30/Adidas-Sales-Performance-Analysis-Uncovering-Key-Insights-for-Growth-2020-2021](https://github.com/Ernest-30/Adidas-Sales-Performance-Analysis-Uncovering-Key-Insights-for-Growth-2020-2021-)

I made some modifications to clean and reformat the data for better analysis.

---

## 🛠 Tools Used

- **Microsoft Excel** – For initial data cleaning and basic manipulation  
- **Power BI** – For building the interactive dashboard and performing visual analysis  
- **GitHub** – For version control and project documentation  

---

## 📊 Dashboard Features

The Power BI dashboard includes:

- **Slicers** to filter data by region, product, date, and more  
- **KPIs** to highlight key metrics like total sales, profit, and units sold  
- **Graphs** including bar charts, pie charts, and line graphs for visual storytelling  
- **Interactive Visuals** to explore trends and patterns across time and categories  


---

## ✅ Conclusion

This project demonstrates how to use public data sources and common analytics tools to gain business insights. It also showcases practical skills in data cleaning, visualization, and storytelling using Excel and PowerBI.
